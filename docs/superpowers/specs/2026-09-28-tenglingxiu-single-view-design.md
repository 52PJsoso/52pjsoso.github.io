# 腾领袖单内容展示调整设计

## 目标

将当前“无界 / 腾领袖”双页签界面调整为单内容界面。页面打开后直接展示现有腾领袖功能，不显示任何产品切换页签。无界功能及其视频资源继续保留在源码中，仅从界面隐藏。

## 展示行为

- 隐藏整个页签区域，因此“无界”和“腾领袖”按钮都不显示，也不占据页面空间。
- 页面初始化为腾领袖展示状态。
- 保持现有腾领袖功能分区、卡片、视频地址和视频弹窗行为不变。
- 隐藏无界功能大全以及全部 `.wujie-section` 分区。
- 不删除、迁移或改写任何无界功能节点及其 `data-video` 资源地址。

## 顶部文案

使用用户选择的直接表述方案，替换现有两条版本与兼容性说明：

> 营销系统只要手机能够解锁 BL 锁并完成 ROOT，即可刷入。
>
> 支持摩托罗拉、联想、一加、小米等品牌；不确定是否兼容，可将手机型号提供给客服咨询。
>
> 我们已经升级至 V8.0.77 版本，请放心购买。

沿用现有成功提示色和居中排版，并将兼容条件、品牌举例、咨询提示及版本信息拆成三行，避免移动端出现过长且难读的单段文字。

## 实现边界

- 在现有 HTML、CSS 和 JavaScript 结构内做最小调整。
- 页签 DOM 可以继续保留，以便未来恢复；使用样式将其完全隐藏。
- JavaScript 默认状态由无界切换为腾领袖。隐藏页签后不再产生用户可见的切换入口。
- 不调整现有视觉主题、功能卡片样式或视频弹窗实现。
- 不删除无界视频资源，不修改任何视频 URL。

## 验证

- 静态检查确认两枚页签不显示，且默认状态为腾领袖。
- 静态检查确认无界节点和视频 URL 仍存在。
- 检查三条新文案及 V8.0.77 版本号准确显示，旧版本号不再显示。
- 在桌面端和移动端视口检查顶部文案、首个功能区及页面间距。
- 点击腾领袖功能卡片，确认视频弹窗仍能打开与关闭。
